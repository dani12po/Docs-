## Phase 1 — MVP

<Badge status="shipped">Shipped</Badge>

The initial phase delivers a complete wallet-first ramp for Top Up and Sell.

- Top Up via MoonPay (fiat to crypto) — credit/debit card, Apple Pay, Google Pay, and bank transfer. MoonPay as merchant of record handling KYC/AML and compliance.
- Sell via crypto deposit to platform → on-chain confirmation → IDR bank payout via MoonPay.
- Assets SOL, ETH, and BNB on testnet (Solana Devnet, Base Sepolia, BSC Testnet).
- Quotes with locked pricing (spread, service fee, network fee, tax).
- Progressive IP bans and Redis rate limiting.
- Admin access key and TOTP.
- Support tickets.
- Privacy-preserving page analytics.
- Double-entry ledger and audit log.

## Phase 2 — Active

<Badge status="active">Active</Badge>

The transaction-based rewards program is running, with payouts in DRY-RUN mode.

- Eligibility, progress tracking, and claim reservation.
- DRY-RUN payouts only: no on-chain treasury access, no signing, no transfers; claims stay `PENDING_PAYOUT`.
- Per-cycle (monthly) qualification.
- Anti-fraud review.
- Terms versioning (`termsVersion 2026-09-v1`).

### Payment Gateway Pilot with MoonPay

<Callout type="info" title="Payment Gateway Partnership with MoonPay">
  KORAMP is running a pilot payment gateway integration with MoonPay as the merchant of record. As the compliance partner, MoonPay handles KYC/AML, fraud verification, and cross-border regulatory compliance — extending KORAMP's service reach to more countries without bearing the internal compliance burden. The integration is in a limited trial phase ahead of a phased rollout to users.
</Callout>

- MoonPay Widget integration pilot — on-ramp (buy crypto) and off-ramp (sell crypto) flows with multi-fiat support (IDR, USD, EUR, and more).
- Web platform in closed beta testing; access is restricted while validating stability, security, and user experience ahead of a public launch.
- Transaction security reinforced with HMAC-SHA256 URL signing and MoonPay webhook signature verification for end-to-end data integrity.
- The architecture is modular by design: MoonPay serves as the primary payment gateway, supporting on-ramp (buy) and off-ramp (sell) across all supported regions.

## Phase 3 — Planned

<Badge status="planned">Planned</Badge>

The next phase moves rewards on-chain and opens mainnet networks.

- Live on-chain reward payouts (broadcast real transactions, confirmation tracking via `confirmations`/`requiredConfirmations`).
- Mainnet networks (Solana Mainnet, Base Mainnet, BSC Mainnet).
- Additional assets (e.g. stablecoins USDC/USDT).
- Webhook reliability hardening.

## Phase 4 — Future

<Badge status="future">Future</Badge>

KORAMP's long-term vision for a broader ecosystem.

- Compliance, AML, and Travel Rule tooling.
- Merchant/hosted-checkout API for third parties.
- Additional fiat rails beyond MoonPay.
- Expanded payout rails.
- Multi-language documentation.
- Public SDK.
