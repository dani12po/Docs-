## Audit Log

`AuditLog` records important actions with the actor (`walletAddress`, admin email, or `system`), entity, entity ID, metadata, and IP address. It's the system-of-record for who did what.

## Double-Entry Ledger

`LedgerEntry` is a double-entry record per wallet and asset:

| Field | Description |
|---|---|
| `walletAddress` | The wallet the entry applies to. |
| `asset` | IDR, SOL, ETH, or BNB. |
| `direction` | CREDIT or DEBIT. |
| `amount` | The entry amount. |
| `reference` | A reference string. |
| `topUpOrderId` / `sellOrderId` | Links to the originating order. |

## Webhook Idempotency

`MoonPayWebhook` enforces idempotency using a unique constraint on `(eventType, transactionId, updatedAt)`. Re-delivered webhooks are de-duplicated against this key, preventing double-fulfillment. Every webhook is verified via the `Moonpay-Signature-V2` header (HMAC-SHA256 over `timestamp.rawBody` using the Webhook API Key).

## Privacy-Preserving Analytics

`PageVisit` records only `path` + UTC `day` with a counter — no IP, user-agent, or fingerprint. One row per `(path, day)`, so traffic never creates unbounded rows.
