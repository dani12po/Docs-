## Overview

This page is a summary of KORAMP's public endpoint groups. Signatures (method and path) follow the real handlers in the app. Non-public endpoints are noted honestly.

## /quotes

Create locked-price quotes for Top Up or Sell.

| Method | Endpoint | Notes |
|---|---|---|
| POST | /quotes/topup | Body `{asset, network, idrAmount}`. Rate limit 30/min. |
| POST | /quotes/sell | Body `{asset, network, idrAmount}`. Rate limit 30/min. |

## /orders

Create and monitor orders.

| Method | Endpoint | Notes |
|---|---|---|
| POST | /orders/topup | Creates a TopUpOrder + MoonPay payment session. |
| POST | /orders/sell | Creates a SellOrder + deposit address + bank payout details. |
| GET | /orders/[publicId] | Order detail by public ID. |
| GET/POST | /orders/[publicId]/payment-status | Payment status. |
| GET | /orders/[publicId]/payout-status | Payout status. |
| POST | /orders/[publicId]/check-delivery | Check crypto delivery. |
| POST | /orders/[publicId]/confirmed-sent | Confirm send. |
| POST | /orders/[publicId]/poll-deposit | Deposit monitoring. |
| POST | /orders/[publicId]/submit-tx | Submit transaction hash. |

## /payments

<Callout type="warning" title="No public endpoint">
There's no separate public `/payments` endpoint. The Payment object (MoonPay session) is created server-side inside `POST /orders/topup`; its status is accessed via `/orders/[publicId]/payment-status`.
</Callout>

## /prices

| Method | Endpoint | Notes |
|---|---|---|
| GET | /prices | Public indicative rate board (SOL/ETH/BNB live + spot + limit IDR). Read-only. |

## /assets

| Method | Endpoint | Notes |
|---|---|---|
| GET | /assets | List of active assets and networks. 60s cache. |

## /wallets

| Method | Endpoint | Notes |
|---|---|---|
| POST | /wallets/validate | Validate address/network/asset combination. |
| POST | /wallets/challenge | Proof-of-ownership nonce. |
| POST | /wallets/verify | Verify signature. |
| POST | /wallets/signature | Signing. |
| GET | /wallets/[address]/orders | Wallet order history (wallet-first). |

## /rewards

| Method | Endpoint | Notes |
|---|---|---|
| GET | /rewards | Reward progress and eligibility by wallet. |
| POST | /rewards/claim | Claim reservation (Phase 2: PENDING_PAYOUT, DRY-RUN). |

## /support

| Method | Endpoint | Notes |
|---|---|---|
| GET/POST | /support | List and submit tickets (order reference required). |
| GET | /support/[publicId] | Ticket detail. |
| GET/POST | /support/[publicId]/messages | Ticket conversation. |

## /transactions

| Method | Endpoint | Notes |
|---|---|---|
| GET | /transactions | Global public ledger; masked wallets; server-side pagination. |

## /webhooks

| Method | Endpoint | Notes |
|---|---|---|
| POST | /webhooks/moonpay | MoonPay transaction callback (`Moonpay-Signature-V2`; HMAC-SHA256 verified). |

Webhooks are signal-only; fulfillment is processed server-side and idempotently.

## /cron

| Method | Endpoint | Notes |
|---|---|---|
| GET | /cron/scan-deposits | Scan Sell deposits. |
| GET | /cron/reconcile | Reconciliation. |

Cron uses a bearer secret and is meant for a scheduler, not a browser.

## /visits

| Method | Endpoint | Notes |
|---|---|---|
| POST | /visits | Privacy-preserving analytics beacon (path + UTC day only). |

| PUT | /admin/fees/bulk | Bulk fee update. |
| PUT | /admin/fees/[key] | Single fee update. |
| GET/POST | /admin/prices | Price management. |
| GET/POST | /admin/keys | Access key management. |
| GET | /admin/orders/topup | List Top Up orders. |
| GET | /admin/orders/sell | List Sell orders. |

| GET/PUT | /admin/rewards | Reward configuration. |
