## Prasyarat

Sebelum mulai, pastikan Anda sudah memahami konsep dasar berikut:

- Model wallet-first dan alamat dompet sebagai identitas.
- Perbedaan Top Up (Rupiah ke crypto) dan Sell (crypto ke Rupiah).
- Aset dan jaringan yang didukung (saat ini testnet).

## 1. Pilih Aset dan Jaringan

Tentukan aset yang akan digunakan. Setiap aset terikat pada satu jaringan:

| Aset | Jaringan | Chain ID |
|---|---|---|
| SOL | Solana Devnet | - |
| ETH | Base Sepolia | 84532 |
| BNB | BSC Testnet | 97 |

## 2. Validasi Dompet

Gunakan endpoint validasi dompet untuk memastikan kombinasi alamat, jaringan, dan aset cocok. Untuk EVM, pengguna perlu menandatangani pesan untuk membuktikan kepemilikan (proof-of-ownership).

## 3. Buat Quote

Quote memberikan harga terkunci untuk jumlah Rupiah atau crypto yang diinginkan. Quote menyimpan komponen harga: harga pasar, spread, biaya layanan, biaya jaringan, dan pajak.

## 4. Buat Order

Setelah quote dibuat, lanjutkan ke pembuatan order:

- **Top Up**: buat order Top Up, bayar via Xendit QRIS, lalu crypto dikirim ke dompet tujuan setelah pembayaran terverifikasi.
- **Sell**: buat order Sell, kirim crypto ke alamat deposit platform, lalu payout Rupiah dikirim setelah deposit terkonfirmasi.

## 5. Pantau Status

Pantau status order dan deposit lewat endpoint status. Untuk Sell, konfirmasi on-chain dilacak lewat jumlah konfirmasi.
