## Kerangka Kerja

| Komponen | Versi | Peran |
|---|---|---|
| Next.js | 14.2.35 | Kerangka App Router (aplikasi utama). |
| React | 18.2.0 | Antarmuka pengguna. |
| TypeScript | 5.3.3 | Pengetikan statis. |
| Prisma | 5.7.1 | ORM dan skema database. |
| PostgreSQL | Neon | Basis data utama. |
| Redis | ioredis 5.11 | Pembatasan laju dan cache. |

## Antarmuka

- **Tailwind CSS** 3.4.0 untuk styling.
- **ethers** 6.9 dan **viem** 2.56 untuk interaksi EVM.
- **@solana/web3.js** 1.99 untuk interaksi Solana.
- **zod** 3.22 untuk validasi input.

## Integrasi Pembayaran

- **MoonPay Widget/Platform** sebagai payment gateway dan merchant of record untuk pembayaran fiat (Top Up) — menangani KYC, AML, fraud, dan compliance lintas-wilayah.
- **MoonPay** juga memproses payout fiat ke rekening bank (Sell).
- URL signing HMAC-SHA256 dan verifikasi webhook `Moonpay-Signature-V2` untuk integritas transaksi.

Provider legacy KiPay, TransFi, dan Xendit sudah pensiun; kolom database disimpan untuk riwayat saja.

## Keamanan

- **jose** 5.2 untuk token sesi.
- TOTP untuk faktor kedua admin.
- Redis untuk pembatasan laju.
